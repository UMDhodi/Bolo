# Bolo — Civic Connect (बोलो नागरिक कनेक्ट)

<!-- CODEX:BEGIN -->
<!-- CODEX:TAGS: openai, codex, civic-tech, react18, typescript, tanstack-router, tailwindcss, leaflet, firebase -->

> A municipal grievance redressal and citizen reporting platform for Indian communities.
>
> **Crafted with OpenAI & Codex**

---

## Features
- 🗺️ **Interactive India Map**: Search and filter civic issues across Indian states, districts, and cities.
- 📸 **Camera & Photo Reporting**: Take live photos or upload images with GPS coordinates.
- 🌐 **8 Regional Languages**: Instant reactive UI switching across English, Hindi, Marathi, Bengali, Tamil, Telugu, Kannada, and Gujarati.
- 👤 **Citizen Profile & KPI**: Verified badge, complaint statistics, and editable profile synced with Firebase Realtime Database.
- ⚡ **Realtime Database**: Real-time synchronization of civic complaints and resolution stages.

For full architecture details, design system, and documentation, see [`PROJECT.md`](./PROJECT.md).

## Quick Start
```bash
npm install
npm run dev
```
